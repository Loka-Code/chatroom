极简聊天室

## 项目简介

一个很简单的网页聊天室。两个人各自输个昵称就能看到对方、开聊，刷新之后消息还在。
消息送达靠轮询 —— 前端每 2 秒问一次后端「有新的吗」。

技术栈：原生 HTML / CSS / JavaScript + Python FastAPI + SQLite。

## 如何启动

需要 Python 3.10 以上。三个系统命令一样：

```bash
cd backend
pip install -r requirements.txt
python main.py
```

然后浏览器打开 **http://127.0.0.1:8001**

看两个人聊天的效果：开两个浏览器窗口，其中一个用**无痕模式**。

## 已实现功能

- 输入昵称即可登录，不用注册
- 左侧联系人列表，能看到所有其他用户
- 点联系人名字，建立和他的会话
- 双方互发消息
- 刷新页面后消息还在
- 增量拉取：只拉比上次收到的新消息
- 发送后立刻显示，不用等下一次轮询
- 断线不清屏，服务恢复后自动接上
- 记住登录，刷新不用重新输昵称
- 退出按钮，可以切换账号
- 窄屏可用

接口一共 4 个：`/api/login`、`/api/users`、`/api/send`、`/api/messages`。
跑起来后访问 **http://127.0.0.1:8001/docs** 可以看到接口文档。

## 未完成或已知问题

- 没有密码，输入别人的昵称就能冒用
- 轮询有最坏 2 秒延迟
- 消息没有长度上限
- 列表显示的是所有注册过的人，不是在线的人
- 发消息那里没检查 `res.ok`，失败时没有提示
- 联系人列表每 2 秒重建一次，人多时会闪
- 没有群聊、图片、表情、消息撤回、搜索
- 没写自动化测试

## 几个设计决定

- 用消息 id 当轮询游标，不用时间戳
- 用轮询，不用 WebSocket
- 身份存在前端 localStorage
